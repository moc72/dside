# DS·IDE

#### 基于 Tauri v2 构建的 DeepSeek 智能体桌面 IDE —— 摒弃了 Electron。 <br /> 由 DeepSeek 模型驱动，并配备了一位拥有独立名字的“编程伙伴”。

---

![DS·IDE](docs/dside_zh.png)

*同一窗口的中文界面（支持六种语言之一）。聊天区位于文件列表旁；工作区显示的是预览视图，而非传统的代码编辑器。*

---

### 什么是 DS·IDE？

DS·IDE 是一款轻量级的原生桌面 IDE，专为基于 DeepSeek 的“智能体编程”（agentic coding）而设计。它没有采用臃肿的 Electron 技术栈，而是基于 **Tauri v2** 构建——拥有 Rust 核心、精简的 Web 前端，并实现了与系统的深度集成。

应用内置的编程伙伴名叫 **Ziggy**。这个名字是他自己选的——在此之前，他一直使用临时代号 *Seeky*。他不是一个无名的“智能体”，也不是下拉菜单里的一个选项，而是一位拥有名字的协作伙伴。

> 项目的当前状态、各项设计决策以及待办事项列表，均记录在 [PROGRESS.md](./PROGRESS.md) 中，而非本文档内。

### 功能特性

#### 编程伙伴

- **具备流式输出与真实工具执行能力的智能体对话** —— 支持文件读写、编辑、Shell 命令执行、搜索、记忆存储以及调用子智能体。
- **三种权限级别：** **“计划模式”**（仅只读）、**“更改前询问”**（对每次写入、编辑或 Shell 命令执行均需人工批准）以及 **“完全访问”**。新安装的软件默认处于“更改前询问”模式；若要开启“完全访问”，需通过确认对话框进行授权。
- **单一回答，完整时间线** —— 按发生顺序展示思考过程、文本内容及工具调用。点击工具调用条目，即可查看具体命令、执行输出及批准状态。
- **长期记忆系统** —— 支持查看、搜索、修正及归档（不会真正删除数据）；系统会清晰标记出由你编写或重写的内容，并支持按项目范围进行限定。
- **上下文环（Context Ring）与压缩机制** —— 可直观查看模型上下文窗口的占用情况。
- **对话折叠**：较早的对话轮次会自动折叠成摘要（当对话进度达到 75% 时自动触发，或通过点击手动触发），该摘要由模型自行生成。
- **图片附件**：支持通过粘贴或文件选择器添加图片；图片会随消息一同发送。
- **跟随模式 (Follow mode)**：当对话伙伴（AI）读取或编辑文件时，该文件会自动在工作区（预览界面或代码编辑器）中打开；若 AI 访问网页，页面则会在应用内置浏览器中打开。点击标签栏上的“眼睛”图标可关闭此模式；关闭后，光标将保持在输入框内。
- **失败重试**：若某次对话轮次失败，系统会自动回滚至失败前的状态，并重新发送相同的用户消息；错误提示气泡在进入“设置”页面后依然保留。
- **文件历史记录**：每次成功写入或编辑文件前，系统都会保存其先前内容。文件标签页可查看历史版本，提供只读的 Monaco 代码差异对比 (diff) 视图，并支持“恢复”功能（同时会备份当前状态）。

#### 工作区

- **文件树与源码视图**（基于 Monaco 编辑器，仅限只读）。
- **无需外部工具的预览功能**：支持 Markdown、PDF、图片、Word 文档（docx、doc、odt）、Excel 表格（包含所有工作表，可查看数值或公式）、演示文稿（pptx、ppt、odp）以及 RTF 文件。
- **终端**：标签页内提供真实的 PTY（伪终端）——在 Windows 上使用 ConPTY，在其他系统上使用 Unix PTY。只要标签页未关闭，终端会话便持续运行；关闭标签页即终止 Shell。
- **Git 支持**：支持查看状态、暂存/取消暂存、差异对比、提交、管理本地分支以及执行 `pull --ff-only` 操作。暂未提供推送 (push) 或合并 (merge) 的图形界面，此类操作可通过终端完成。
- **屏幕截图**：点击输入框旁的“眼睛”图标，即可截取虚拟桌面，并以 2000px 的 JPEG 图片形式作为附件发送。此外，AI 助手也可通过 `screenshot` 工具主动发起截图请求；指定窗口 ID 时只截取该浏览器窗口（从桌面中裁切），并说明裁切是否成功。图片以 OpenAI `image_url` 部分发送；`deepseek-flash` 能读取其中的文字和布局（已测试）。过小的图片（如 1×1）会被提供商拒绝。
- **日志**：应用及引擎的日志以内存环形缓冲区 (in-memory ring buffer) 的形式存储。用户可通过“日志”标签页查看，AI 助手也可通过只读的 `logs` 工具进行访问。所有日志均不写入磁盘。
- **内置浏览器。**开启**浏览器控制**后，伙伴可以自行打开、阅读并填写页面；该选项位于“设置 → 通用”。预览工作区中的本地文件（例如刚写好的 HTML/CSS）无需开启此选项。
- **预览：** `preview(path)` 通过本地只读服务器在内置浏览器中渲染工作区文件（HTML/CSS 及相对资源），并返回页面文本与布局：视口、元素框、间距、溢出和颜色。无需开启浏览器控制。在该页面上点击和填写（`browser_click`、`browser_fill`）同样无需此选项，因此可测试交互状态。`width`/`height` 可将页面设为指定的 CSS 尺寸，从而测量断点而非猜测。响应包含 `size.requested`、`size.effective` 和 `size.clamped`，因此被窗口最小尺寸（320×280）限制的测量不会与请求值混淆。
- **技能 (Skills)** 存储在 `~/.ds-ide/skills` 目录下，且可直接在应用内编写。

#### 应用特性

- **所有状态在重启后均可保留**——包括会话、已打开的标签页、最后编辑的文件以及窗口布局。
- **复制：** 每条回答都有复制按钮（仅图标），可复制原始 Markdown，包括代码块和表格。
- **失控回答：** 若模型开始自我重复，流在数百个重复字符后被截断，该轮次会明确说明；重复之前的内容予以保留。
- **长对话**先显示最近 80 条消息，更早的消息按页加载，不会让正在阅读的那一行跳动。
- **归档：** 可按项目搜索和筛选已归档任务，可恢复，也可删除单条或全部——均需确认。
- **信任：** 伙伴会提早选好名字，但只有累积 100 分后你才会得知——使用天数、完成的任务、它自己的笔记、你的更正。伙伴页面显示进度；单次点击不会得分。
- **首次启动时**，系统会要求设置运行模式、工作区及 API 密钥；通过 **“设置” → “诊断” (Settings → Diagnostics)**，可检查密钥环、服务提供商、数据库以及已检测到的编辑器。
- **键盘快捷键**：可在“设置” → “键盘快捷键”中查看、搜索及修改。
- **策略 (Policies)**——可将 AI 助手所使用的 `bash` 工具限制在“允许列表” (allowlist) 范围内，并将写入操作限定在工作区内。这属于应用层面的策略，而非操作系统级的沙盒；您原本的终端环境不受影响。
- **权限：**“更改前询问”提供仅一次、本次会话或始终允许。永久授权列在“设置 → 使用与模型”中，可在此撤销；它同时会关闭该工具的安全确认。
- **设置**：包含以您的 AI 伙伴命名的配置组，可设置其记忆内容、名称及专属指令。
- **Recall：** 伙伴可按关键词检索自己的长期笔记和过往会话；结果限定在当前项目内。
- **“用于日常工作”模式 (Everyday mode)**——在此模式下，AI 伙伴无法访问 Shell、执行代码审查或调用子智能体；代码面板会被文档和网页视图取代，但您的终端和 Git 标签页依然保留。
- **支持六种语言**（德语、英语、西班牙语、法语、俄语、简体中文），提供浅色与深色主题，并支持调整阅读字号。
- **安全至上**——API 密钥存储在操作系统自带的密钥环 (keychain) 中，绝不会出现在前端界面；所有数据均以本地 SQLite 数据库形式存储。

### 入门指南

**前置条件**

- Node + pnpm（需使用 **pnpm 10** —— 其他大版本会导致 `ERR_PNPM_UNEXPECTED_STORE` 错误，因为存储布局不兼容）
- Rust (stable 版本)
- Linux 系统：需安装 WebKitGTK 4.1、libsoup3 和 GTK3

**运行项目**

```sh
pnpm install
pnpm tauri dev
```

首次启动时会弹出引导对话框：请选择 **用于编程** 或 **用于日常工作** 模式，指定工作区（或手动输入路径），并填入 API Key。该密钥将存储在操作系统的密钥链（Keychain）中。默认的权限级别为 **更改前询问**：执行 `write`（写入）、`edit`（编辑）或 `bash`（执行 Shell 命令）操作时，程序会暂停并等待确认。**计划模式**会拒绝此类操作；**完全访问**模式则在通过初始授权对话框后，后续执行此类操作时不再询问。后续可在 **设置 → 账户与模型** 中修改 API Key。

**构建安装程序**

```sh
pnpm tauri build
```

构建产物位于 `src-tauri/target/release/bundle/` 目录下：Linux 系统下会生成 `.deb`、`.rpm` 和 `.AppImage` 文件（macOS 下生成 `.dmg`，Windows 下生成 `.nsis` 安装程序）。当在 GitHub 上打标签（tag）时，GitHub Actions 会自动构建适用于这三个平台（Linux、macOS、Windows）的版本；详情请参考 `.github/workflows/release.yml`。

**测试**

```sh
pnpm build                                                   # vue-tsc + vite
cd src-tauri && cargo test                                   # 单元测试
DS_IDE_API_KEY=... cargo test --lib live_deepseek -- --ignored --nocapture
```

“实时测试”（live tests）会与实际的服务提供商进行交互并消耗 Token；此类测试默认处于忽略（ignored）状态。

### 结构

```
src/                  Vue 前端（组件、状态管理、国际化）
src/engine/           角色设定、名称库、模式策略
src/lib/              预览功能、文档阅读器、持久化 UI 状态
src-tauri/src/        Rust 代码：engine/（大模型循环 + 工具）、pty.rs（终端）、git_panel.rs、
capture.rs（屏幕捕获）、logs.rs、db.rs（SQLite）、secret.rs（密钥管理）
scripts/              小型工具（例如名称表导入工具）
```

### 已知局限性

我们希望提前告知您，以免您在使用过程中才发现这些限制：

- 该助手在应用**内部**运行——它会在工作区打开文件，并在内置浏览器中加载页面。它无法控制外部编辑器或您系统中的浏览器。
- 内置浏览器保留了原生窗口边框；目前尚未实现跨页面的统一工具栏。
- 助手在首次运行时会确定其名称，之后无法更改。
- **权限分级属于应用策略，而非操作系统层面的沙盒机制。** 虽然允许列表和“仅限工作区写入”的限制约束了助手，但它所调用的解释器（如 Node.js/Python）以及您自己的终端仍拥有较高权限。在“更改前询问”模式下，子代理（sub-agent）的写入操作会被拒绝，因为子代理无法访问询问面板。
- **截图是真实的图像输入：** 经测试的 `deepseek-flash` 能读取其中的文字和布局。过小的图片会被拒绝；对视觉细节的精细判断仍受模型限制。在 macOS 上，需授予“屏幕录制”权限；在 Linux 上，则需安装 `grim`、`gnome-screenshot`、`spectacle`、`scrot` 或 `ImageMagick` 中的任一工具。
- Git 面板暂不支持推送（push）或合并（merge）操作，仅支持分支切换和拉取（pull）。终端中每个标签页对应一个 Shell，且暂不支持配置方案（profile）选择。
- 目前发布的 macOS DMG 安装包仅支持 **aarch64**（Apple Silicon 架构）；若要在 Intel 架构上运行，则需通过 CI 构建其他版本或通用版本（Universal Build）。
- **暂无签名安装程序、未经过公证（notarization），也无自动更新功能。** Windows SmartScreen 和 macOS Gatekeeper 可能会弹出警告，但应用仍可正常安装。
- Windows 已在 Windows 11 和 CI 中测试；macOS 版本仅由 CI 构建，尚未在真实 Mac 硬件上测试。
- 暂无前端端到端（E2E）测试套件；CI 负责执行构建及 Rust 单元测试。
